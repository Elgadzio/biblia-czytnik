# Biblia – czytanie

Prosta aplikacja (PWA) na iPhone'a do czytania Pisma Świętego (Biblia Tysiąclecia) rozdział po rozdziale
i oznaczania przeczytanych rozdziałów. Tekst rozdziałów wyświetlany jest z serwisu biblia.deon.pl;
postęp zapisywany jest lokalnie na urządzeniu.

Instalacja: otwórz stronę w Safari → Udostępnij → „Do ekranu początkowego”.
